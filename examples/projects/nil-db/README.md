# 🗄️ NilDB: ইন-মেমরি রিলেশনাল ডেটাবেস ও কুয়েরি ইঞ্জিন (Nilang)

**NilDB** হলো নীলাং (Nilang) প্রোগ্রামিং ভাষায় লিখিত একটি হালকা অথচ অত্যন্ত শক্তিশালী ইন-মেমরি রিলেশনাল ডেটাবেস ইঞ্জিন (In-Memory Relational Database Engine)। এটি টেবিল স্কিমা ভ্যালিডেশন, প্রাইমারি কী ইউনিকনেস, সম্পূর্ণ CRUD অপারেশন এবং SQL-স্টাইল কুয়েরি ফিল্টারিং সাপোর্ট করে।

## ⚡ মূল ডেটাবেস ফিচারসমূহ

1. **স্ট্রং স্কিমা এনফোর্সমেন্ট (`src/schema.nil`):**
   - কলামে `INT`, `STRING`, `FLOAT`, `BOOL` টাইপ ডিক্লারেশন।
   - বাধ্যতামূলক ফিল্ড (`isRequired`) থাকলে তা পূরণ ছাড়া ইনসার্ট প্রতিরোধ করা হয়।
   - প্রাইমারি কী ইউনিকনেস স্বয়ংক্রিয়ভাবে বজায় থাকে।

2. **সম্পূর্ণ CRUD কার্যক্ষমতা (`src/table.nil`):**
   - **Create:** `insert(table, data)` — স্বয়ংক্রিয় অটো-ইনক্রিমেন্ট আইডি প্রদান।
   - **Read:** `findById(table, id)` ও `getAllRows(table)`।
   - **Update:** `update(table, id, updates, keys)` — নির্দিষ্ট রেকর্ডের নির্দিষ্ট ফিল্ড আপডেট।
   - **Delete:** `deleteById(table, id)` — নিরাপদ ও ক্লিন ডিলিট।

3. **কুয়েরি ফিল্টার ও প্রজেকশন (`src/query.nil`):**
   - **WHERE ফিল্টারিং:** `where(rows, "price", Types.OP_GT, 5000)`।
   - **কলাম প্রজেকশন:** `selectColumns(rows, ["name", "price"])`।
   - **লিমিট রেজাল্ট:** `limit(rows, 2)`।

4. **পরিসংখ্যান ও এগ্রিগেশন:**
   - **SUM:** `sumColumn(rows, "price")` দিয়ে কলামের মোট যোগফল নির্ণয়।
   - **AVG:** `avgColumn(rows, "price")` দিয়ে গড় মান নির্ণয়।
