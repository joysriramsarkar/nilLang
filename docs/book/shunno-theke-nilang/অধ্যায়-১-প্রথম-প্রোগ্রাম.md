# অধ্যায় ১ — প্রথম প্রোগ্রাম

এই অধ্যায়ে নীলাং ইনস্টল করে প্রথম প্রোগ্রাম চালাবে।

## ১.১ ইনস্টল যাচাই

```sh
nil version
# Nilang Compiler v0.1.0
```

সংস্করণ-সংখ্যা দেখা মানেই টুলচেইন প্রস্তুত।

## ১.২ হ্যালো, নীলাং

`প্রথম.nil` নামে ফাইল লেখো:

```nil
println("হ্যালো, নীলাং!");
```

চালাও:

```sh
nil run প্রথম.nil
# হ্যালো, নীলাং!
```

`println` লেখার শেষে নতুন লাইন দেয়; `print` দেয় না।

## ১.৩ হিসাব-নিকাশ

নীলাং ক্যালকুলেটর হিসেবেও চলে:

```nil
let দাম = 150;
let কর = দাম * 15 / 100;
println("মোট: " + str(দাম + কর));
```

```sh
nil run হিসাব.nil
# মোট: 172
```

লক্ষ করো:
- `let` দিয়ে চলক ঘোষণা হয়।
- `str(...)` সংখ্যাকে লেখায় বদলায় (লেখা + সংখ্যা সরাসরি জোড়া যায় না)।
- বাংলা নাম (`দাম`, `কর`) পুরোপুরি বৈধ — নীলাং UTF-8 আইডেন্টিফায়ার চেনে।

## ১.৪ ভুল হলে কী দেখায়

```nil
let x = 10;
let y = x + "টি";
```

```sh
nil run ভুল.nil
# ❌ ... টাইপ/রানটাইম ত্রুটি ...
```

নীলাং ভুলের জায়গা (লাইন:কলাম) ও কারণ বাংলাসহ জানায়। `nil check ভুল.nil`
চালালে না-চালিয়েই ত্রুটি দেখা যায়।

## ১.৫ অনুশীলনী

1. তোমার নাম ও জন্ম-বছর print করো।
2. জন্ম-বছর থেকে বয়স হিসাব করে `str()` দিয়ে জোড়া লাগাও।
3. ইচ্ছা করে একটি টাইপ-ভুল করে `nil check`-এর বার্তা পড়ো।

পরের অধ্যায়ে চলক, ফাংশন আর লুপের পুরো ছবি দেখবো।
