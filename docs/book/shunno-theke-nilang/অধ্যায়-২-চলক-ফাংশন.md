# অধ্যায় ২ — চলক, ফাংশন ও নিয়ন্ত্রণ

## ২.১ `let` ও `const`

```nil
let নাম = "রহিম";      // বদলানো যায়
নাম = "করিম";
const দেশ = "বাংলাদেশ"; // বদলানো যায় না
```

একই স্কোপে দুবার `let` নয়; বদলাতে শুধু `=` ব্যবহার করো।

## ২.২ ফাংশন

```nil
let যোগ = fn(a, b) {
    return a + b;
};
println(str(যোগ(40, 2))); // 42
```

- `fn` দিয়ে ফাংশন-মান তৈরি হয়; নামে রাখলে ডাকা যায়।
- `return` না থাকলে শেষ এক্সপ্রেশনের মান ফেরত যায় না — সবসময় `return` লেখো।
- রিটার্ন-টাইপ চাইলে: `fn যোগ(a: Int, b: Int) -> Int { return a + b; }`।

ক্লোজার বাইরের চলক ধরে:

```nil
let গুণক = 10;
let গুণ = fn(x) { return x * গুণক; };
println(str(গুণ(4))); // 40
```

## ২.৩ শর্ত: `if`/`else`

```nil
let নম্বর = 82;
if (নম্বর >= 80) {
    println("A+");
} else {
    if (নম্বর >= 60) {
        println("পাস");
    } else {
        println("ফেল");
    }
}
```

## ২.৪ লুপ: `while` ও `for`

```nil
// while
let i = 0;
while (i < 3) {
    println(str(i));
    i = i + 1;
}

// for — রেঞ্জ, অ্যারে, সূচকসহ
for n in 0..3 {
    println(str(n)); // 0 1 2
}
let ফল = ["আম", "জাম", "কাঁঠাল"];
for f in ফল {
    println(f);
}
for idx, f in ফল {
    println(str(idx) + ": " + f);
}
```

`break` লুপ থামায়, `continue` বাকিটা এড়িয়ে পরের বার চালায়।

## ২.৫ অ্যারে ও হ্যাশ

```nil
let সংখ্যা = [1, 2, 3];
সংখ্যা = push(সংখ্যা, 4); // push নতুন অ্যারে দেয়!
println(str(len(সংখ্যা))); // 4

let ছাত্র = {"নাম": "রহিম", "রোল": 7};
println(ছাত্র["নাম"]);
ছাত্র["রোল"] = 8;
```

মনে রেখো: `push` পুরোনো অ্যারে বদলায় না — ফেরত মানটি রাখতে হয়।
